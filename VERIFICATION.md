## Additional observations

- Exporting with no displayed shipments produced understandable feedback.
- Failed retrieval cleared the shipment list and identified that no current data was available.
- Server address, branch, request mode, timeout, and export path were configurable through the interface.
- Normal mode was restored after testing.

## Verification limits

Testing used the instructor’s local fixture service and controlled test modes. It was not a production load test.

The existing-file case verified export error handling. Other file failures, such as disk-full conditions, were not separately tested.

Results are based on HTTP interactions, application behavior, and inspection of exported CSV contents. Screenshots and successful compilation alone are not treated as complete verification.
