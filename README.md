## Overview

HubLink is a C# and Avalonia desktop client that retrieves shipment information from the instructor-provided HTTP API. It supports status filtering, branch-wide summary counts, asynchronous refresh, error feedback, and CSV export.

## Requirements

- .NET 10 SDK
- Internet access for initial dependency restoration
- Instructor-provided HubLink local server package for Windows x64

## Start the instructor’s server

1. Extract the complete server ZIP.
2. Keep HubLink-Service beside the supplied Start files.
3. Run Start-HubLink.cmd.
4. Keep the server window open.

The default address is:

```text
http://127.0.0.1:5080
```

If port 5080 is occupied, use Start-HubLink-5081.cmd and configure the client to use port 5081.

The server package is supplied separately by the instructor.

## Build and run the client

Open PowerShell in the folder containing this README:

```powershell
cd .\HubLink
dotnet restore
dotnet build
dotnet run
```

No local database or migrations are required.

## Configuration

The interface provides editable fields for:

- Server address
- Branch code
- Request mode
- Timeout in seconds
- CSV destination

Defaults are server http://127.0.0.1:5080, branch BR-001, mode normal, and timeout 5 seconds.

These settings apply to the current application session. They can be changed without editing business logic.

## Using HubLink

1. Start the instructor’s server.
2. Open HubLink and check the connection settings.
3. Click Refresh / Retry.
4. Select a status filter.
5. Enter a full CSV destination ending in .csv.
6. Click Export Displayed Shipments.

The summary always represents all retrieved branch shipments. The filter changes the displayed list and exported records.

Changing the address, branch, or request mode clears previously loaded data. Failed retrieval also clears data so it cannot appear to be a successful refresh.

## API behavior

Normal requests use:

```text
GET /api/shipments?branchCode=BR-001
```

Controlled test modes use:

```text
GET /api/test/shipments?branchCode=BR-001&mode=MODE
```

Supported test modes are empty, bad-request, server-error, invalid-json, and delay. The delay mode waits approximately 10 seconds.

Restore mode normal after testing.

## CSV export

Columns are:

```text
TrackingNumber,Origin,Destination,Status,LastUpdatedUtc
```

Exports contain exactly the displayed records. Text values are quoted, embedded quotation marks are doubled, and timestamps are written in UTC.

An existing destination file is preserved; use a new filename for another export. The destination folder must already exist.

Exports with no displayed records are rejected with feedback.

## Architecture

- Models: shipment and API response data.
- ShipmentApiService: HTTP requests, JSON interpretation, and response validation.
- CsvExportService: CSV formatting and file writing.
- HubLinkViewModel: loading state, filters, summaries, commands, and feedback.
- Views: Avalonia XAML interface.
- App.axaml.cs: constructs the services and connects the ViewModel.
